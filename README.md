# dsh-balance

[![self-check](https://github.com/execrat1on/dsh-balance/actions/workflows/test.yml/badge.svg)](https://github.com/execrat1on/dsh-balance/actions/workflows/test.yml)
[![license: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

Плагин для **DeepSeek Harness**: остаток на API DeepSeek всегда виден в низу левой
колонки, рядом с шестерёнкой настроек, и не требует открывать Settings.

| Состояние | Широкая колонка | Свёрнутый рейл (56 px) |
|---|---|---|
| Обычный тариф | `● $3.92 ! USD` | `$3.92 !` |
| Пиковые часы | `● $3.92 ! USD` — знак горит жёлтым и пульсирует | `$3.92 !` |
| Загрузка | `● …` | `…` |
| Ошибка | `● !` красным, причина в подсказке | `!` |

## Что делает

* **Показывает остаток** — `total_balance` из `GET https://api.deepseek.com/user/balance`.
  В подсказке при наведении — разбивка на подарочные и пополненные деньги с процентами.
* **Помечает пиковые часы** — восклицательный знак в кружке справа от суммы:

  | Вид | Что значит |
  |---|---|
  | Жёлтый, со свечением и пульсацией | Пиковые часы: токены стоят **в 2 раза дороже** |
  | Серый, без свечения | Вне пика: действует обычная (вдвое меньшая) цена |

  Пиковое окно — `01:00–04:00` и `06:00–10:00` UTC, понедельник–пятница; выходные
  целиком вне пика. Окно считает **хост по UTC-часам**, а не браузер по локальному
  времени, поэтому знак не зависит от часового пояса и переключится в течение минуты
  после границы. Если тариф ещё не пришёл, знак не рисуется: плагин не угадывает.
* **Обновляется по клику** — нажатие на чип делает `?refresh=1` и сбрасывает
  серверный кэш, так что сумма меняется сразу. Без клика чип опрашивает маршрут раз
  в минуту, попадая в тот же кэш: лишних запросов к API нет.
* **Локализован** — English, Русский, 中文. Язык подхватывается из активной локали
  Harness; те же строки используются в `title` и `aria-label`, поэтому знак и сумма
  читаются скринридером.
* **Следует теме** — только токены темы (`--dsw-alias-*`), ни одного зашитого цвета,
  а `prefers-reduced-motion` отключает пульсацию знака.

## Установка

Требования: DSH `>= 0.2.0-rc.2`, Node.js `>= 20`.

**Одной командой.** `dsh plugin` — обёртка над pnpm: команда клонирует публичный
репозиторий и ставит плагин в профиль.

```powershell
dsh plugin --profile web add github:execrat1on/dsh-balance#v1.0.0
```

Профиль `web` — тот, что запускается как `dsh web`; подставьте свой, если он называется
иначе. Нужен `git` в `PATH` (на Windows подойдёт portable MinGit). Проверено: установка
через pnpm 12.6.0 ставит `dsh-balance 1.0.0` вместе с `client.js`, `cordis.patch.yml`,
`index.js`, `icon.svg` и `locale/`.

**Через менеджер плагинов.** Settings → Plugins → установка бандла, источник
`GitHub`, репозиторий `execrat1on/dsh-balance`. Клонирование делает `git`, поэтому он
должен быть доступен в `PATH`.

**Из tarball (если git недоступен).**

```powershell
git clone https://github.com/execrat1on/dsh-balance.git   # или скачайте архив и распакуйте
cd dsh-balance
npm pack                                                  # получится dsh-balance-1.0.0.tgz
```

Затем установите бандл из полученного `.tgz` (абсолютным путём) — tarball удалять
нельзя, профиль ссылается на него.

**Ключ API.** Хост читает ключ из переменной окружения:

```powershell
$env:DEEPSEEK_API_KEY = 'sk-...'
```

или из управляемого файла `$DSH_HOME/.credentials.yaml` (по умолчанию
`~/.dsh/.credentials.yaml`):

```yaml
DEEPSEEK_API_KEY: sk-...
```

Без ключа плагин честно показывает ошибку: `● !` красным, а в подсказке — причину.
Ключ нужен только для чтения баланса; ни одна другая часть плагина его не использует.

**Перезапуск.** После установки перезапустите Harness: список клиентских модулей и
манифест читаются на старте.

## Настройка

Строка плагина в профиле принимает один параметр:

```yaml
- id: dsh-balance
  config: { cacheSeconds: 60 }
```

`cacheSeconds` — сколько секунд хост-маршрут отдаёт закэшированный ответ (по умолчанию
60, он же период опроса чипа). Меньше ставить не стоит: каждый промах кэша — это запрос
к `/user/balance`.

## Как это работает

| Слой | Файл | Что делает |
|---|---|---|
| Хост | `index.js` | Регистрирует `GET /dsh-balance/usage`, отвечает только на loopback, кэширует отчёт |
| Хост | `balance.js` | Читает ключ, спрашивает баланс, считает пик/вне пика по UTC. Обычный Node — тестируется и запускается отдельно |
| Браузер | `client.js` | Чип в слоте `sidebar.footer.action`: один `fetch`, три состояния, знак тарифа |
| Манифест | `package.json`, `cordis.patch.yml` | Бандл-патч + клиентский модуль для платформы `web` |

Проверить хост-логику без Harness:

```powershell
node balance.js --table
```

```
tariff: off-peak — normal price
balance: $3.92 USD (granted $1.10 = 28.06%, topped up $2.82 = 71.94%)
prices: https://api-docs.deepseek.com/quick_start/pricing/ (checked 2026-09-29)
```

### Безопасность

* Ключ читает **только хост**; в браузер уходит сумма, валюта и флаг тарифа — не ключ.
* Маршрут отвечает исключительно на `127.0.0.1` / `::1`; запрос с другого адреса
  получает `403` и даже не обращается к API. Это важно, если webserver слушает все
  интерфейсы.
* Браузерная половина не требует ни одного пакета Harness, кроме `react`, и не делает
  сетевых вызовов никуда, кроме собственного хост-маршрута.
* Никаких телеметрий и внешних CDN: только `api.deepseek.com` с хоста.

## Разработка

```powershell
npm test          # node test/verify.mjs
```

Самопроверка без тест-фреймворка и без сети: 120 проверок — пиковое окно по UTC,
чтение ключа из окружения и из `.credentials.yaml`, разбор ответа баланса, ошибки
HTTP, кэш и loopback-фильтр маршрута, регистрация слота, все три состояния чипа,
жёлтый/серый знак, локальные словари на трёх языках, «в стилях нет зашитых цветов»
и «браузер не знает ключа».
